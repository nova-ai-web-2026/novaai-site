# حياة الحارة 🇪🇬

A browser-based Egyptian life-simulator prototype built with Babylon.js and procedural geometry.

## Current gameplay
- First-person exploration on desktop and mobile.
- Procedural Egyptian-inspired urban blocks, ground-floor Arabic shopfronts, balconies, AC units, rooftop tanks and satellite dishes.
- Grocery, koshary, traditional café, bakery, juice and roastery interactions.
- Money, hunger, energy and mood systems.
- Day/night cycle, pedestrians and moving cars/microbuses.
- Delivery-job loop, home/rest interaction and localStorage auto-save.
- Minimap and mobile touch controls.

## Run
Open `index.html` through a static web server or GitHub Pages. Internet access is needed for the Babylon.js CDN.

## Design note
This is a fictional neighborhood inspired by everyday Cairo street-life details rather than a 1:1 reconstruction of a real district. The goal is to expand it in versions: interiors, richer NPC schedules, traffic logic, jobs, apartments, public transport, weather, voice-free ambient audio, and more districts.
