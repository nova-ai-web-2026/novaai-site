# ECHO//17

An original interactive cinematic sci-fi prototype built around branching choices and persistent consequences.

## Story
Astra Bay, 2061. Synthetic courier S-17 discovers an unauthorized human memory containing evidence of a corporate cover-up. The player decides whether to protect a witness or obey a recall order, then makes two more consequential choices.

## Branching structure
- 3 decision levels
- 8 reachable endings
- End-of-chapter flowchart
- Browser auto-save
- Arabic UI with English choice subtitles
- Full-screen 16:9 video-first presentation

## Endings
1. Open Signal
2. Silent Freedom
3. Controlled Truth
4. Broken Trust
5. Reset
6. Witness Protocol
7. City Lockdown
8. New Voice

## Video status
The playable prototype currently embeds 15 lightweight MP4 motion placeholders (7 decision scenes + 8 endings). The game engine is ready for one-to-one replacement with generated cinematic clips.

Higgsfield generation was not charged because the connected account had only 0.84 credits during this build, while the tested minimum suitable video configuration required 4 credits for a single 4-second clip.

## Originality
This project borrows the *interactive narrative design pattern* of branching cinematic games, not protected characters, dialogue, scenes, or plot from Detroit: Become Human.
