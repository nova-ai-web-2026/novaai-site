# ECHO//17 Fast AI-Video Branch

A short interactive cinematic structure built for real AI-generated video clips only.

## Runtime path
Every playthrough contains exactly three clips:

1. `intro`
2. `obey` **or** `protect`
3. one of six ending clips

## Required clips
- `intro`
- `obey`
- `protect`
- `reset`
- `silent`
- `protocol`
- `escape`
- `signal`
- `truth`

Total: **9 unique AI videos, 6 endings**.

The HTML intentionally contains no fake or procedural placeholder videos. Start remains locked until every scene has a real video URL in the `SCENES` object.

Prompts are in `scene-prompts.md`.
