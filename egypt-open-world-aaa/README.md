# مشروع: شوارع النور — Vertical Slice

نموذج أولي أصلي للعبة عالم مفتوح مصرية حديثة، منفصل تمامًا عن أي IP أو أصول أو خرائط أو شخصيات أو واجهات أو موسيقى تابعة لألعاب أخرى.

## التشغيل
افتح `index.html` من خلال خادم HTTP محلي أو GitHub Pages.

مثال:

```bash
python -m http.server 8080
```

ثم افتح:

`http://localhost:8080/egypt-open-world-aaa/`

## محتوى النسخة الأولى
- شخصية قابلة للحركة بمنظور ثالث.
- شقة بداية وممر خروج.
- شارع رئيسي ومحل فول/طعمية.
- 12 شخصية NPC تتحرك وتتفاعل.
- مرور متحرك وإشارة مرور.
- عربية قابلة للقيادة.
- اصطدامات أساسية مع العالم والشخصيات.
- مهمة افتتاحية: «هات الفطار».
- حوار مصري وواجهة عربية RTL.
- حفظ/تحميل عبر LocalStorage.
- دورة ليل/نهار مبسطة.
- نظام بلاغ/سخونة شرطة أساسي بدون ظهور فوري غير منطقي.

## التحكم
- `WASD` أو الأسهم: حركة.
- `Shift`: جري.
- `E`: تفاعل / دخول أو خروج من العربية.
- `R`: إعادة المهمة الحالية.
- `F5`: حفظ سريع من القائمة أو زر الحفظ.

## المعمارية
- `src/data.js`: بيانات الشخصيات والمهمات والمحلات والحوارات.
- `src/systems.js`: الوقت، الحفظ، المهمة، المرور، الشهود، الشرطة، الاقتصاد.
- `src/world.js`: بناء العالم، الشخصيات، العربيات، المتجر، الإضاءة.
- `src/game.js`: حلقة اللعب، الحركة، التفاعل، الكاميرا، ربط الأنظمة.

## ملاحظات إنتاجية
هذه النسخة Vertical Slice وليست لعبة AAA مكتملة. الهدف إثبات جودة المعمارية والـ core loop قبل التوسع إلى الأحياء، interiors الإضافية، الاقتصاد الكامل، الموبايل، الشرطة المتقدمة، الراديو، الأنشطة، والمهام القصصية.
