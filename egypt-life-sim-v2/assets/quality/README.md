# Material source

`egypt-materials.webp` is an original generated material atlas created for Egyptian Life 11.23. It is 1254 × 1254 pixels, converted from the original PNG to WebP at quality 88. No third-party game assets were copied.

The generation brief called for a 4 × 4 grid of natural material surfaces without labels: baladi bread crust, ivory cotton, blue denim, brown leather, aged plaster, red brick, asphalt, pavement slabs, brushed steel, walnut, woven palm reed, worn green paint, ceramic glaze, cream tiles, terracotta and kraft paper.

The runtime crops these cells into shared diffuse textures. Geometry supplies the bread rim, clothing contours, pot rims, handles and bottle necks. The rendering uses standard materials, ACES tone mapping and nearby shadow casters; it does not use photogrammetry or claim photorealistic rendering.

Balanced mode caps display density at 1.25 and uses a 1024-pixel shadow map. High mode caps density at 2 and uses a 2048-pixel shadow map. The preference persists locally. Q or the visible quality button changes the mode.
