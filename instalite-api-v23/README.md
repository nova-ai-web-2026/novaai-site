# InstaLite API v23 — Qwen 3.8

Deploy this folder as a separate Vercel project with Root Directory set to `instalite-api-v23`.

Required Vercel environment variable:
- `DASHSCOPE_API_KEY` = dedicated Alibaba Model Studio Token Plan API key (`sk-sp-...`)

Optional environment variable:
- `DASHSCOPE_BASE_URL` = `https://coding.dashscope.aliyuncs.com/v1`

Model: `qwen3.8-max-preview`
