# InstaLite — Qwen 3.8 Max Preview

This folder is a Vercel-ready chat test using only `qwen3.8-max-preview`.

## Required secret

`BAILIAN_TOKEN_PLAN_API_KEY`

## Optional

`BAILIAN_TOKEN_PLAN_BASE_URL`

Default endpoint used by the API is the Alibaba Model Studio Token Plan international endpoint:

`https://token-plan.ap-southeast-1.maas.aliyuncs.com/compatible-mode/v1`

The API key must remain server-side. Do not place it in `index.html` or commit it to GitHub.
